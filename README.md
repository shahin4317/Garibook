# 🚗 Garibook

A modern and responsive ride-booking web experience designed to make everyday travel simple, flexible, and comfortable.

Garibook allows users to explore different ride services, choose suitable vehicles and drivers, and discover a smooth way to plan their journeys.

## 🌐 Live Demo

**Live Website:** https://garibook-xi.vercel.app

---

## ✨ Features

* 🚘 Modern and responsive landing page
* 📍 City rides and intercity travel services
* ✈️ Airport transfer and rental options
* 🧳 Travel and long-trip use cases
* 📝 Blog and travel inspiration section
* 🛣️ Step-by-step "How It Works" journey section
* 🎨 Clean and minimal UI design
* 📱 Fully responsive across desktop, tablet and mobile
* ✨ Smooth GSAP-powered scroll animations
* ⚡ Fast and lightweight frontend experience
* ♿ Accessible and user-friendly interface

## 🎨 Design

The interface focuses on a clean, modern and travel-friendly visual style.

### Design Principles

* Minimal and spacious layouts
* Clear typography hierarchy
* Soft neutral backgrounds
* Blue accent colors
* Large photography
* Rounded cards and components
* Subtle hover interactions
* Smooth scroll-based animations

The goal is to keep the interface visually engaging without making it feel overly animated or complicated.

---

## 🎬 Animations

GSAP is used to add subtle interactions and scroll animations throughout the experience.

Examples include:

* Section reveal animations
* Image entrance animations
* Staggered content animations
* Journey step animations
* Floating card animations
* Smooth hover transitions

Animations are intentionally kept subtle so that they enhance the user experience without distracting from the content.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Navigate to the project

```bash
cd garibook
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```

---

## 📦 Build for Production

To create a production build:

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```
